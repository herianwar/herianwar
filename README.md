# herianwar

Aplikasi web stok opname sederhana untuk parfum refile menggunakan Flask dan SQLite.

## Menjalankan aplikasi

1. Pastikan Python 3 dan pip telah terpasang.
2. Instal dependensi:
   ```bash
   pip install flask
   ```
3. Jalankan aplikasi:
   ```bash
   python app/app.py
   ```
4. Buka browser ke `http://localhost:5000` untuk melihat aplikasi.
